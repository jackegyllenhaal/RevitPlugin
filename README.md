# RevitPlugin

Плагин автоматического армирования стен выбранной сборки в Autodesk Revit 2023.

Создаёт основную вертикальную и горизонтальную арматуру, арматуру узлов,
шпильки и П-образные стержни. Команда: `RevitPlugin.HelloRevit`.

## Требования

- Windows, Autodesk Revit 2023.
- .NET Framework 4.8 targeting pack и .NET SDK с поддержкой сборки проекта.
- PowerShell 7 для регрессионных проверок.

Пути к `RevitAPI.dll` и `RevitAPIUI.dll` задаются в `RevitPlugin.csproj`.
При другом пути установки Revit обновите `HintPath`.

## Сборка

```powershell
dotnet build
```

Если основная DLL занята запущенным Revit, соберите в отдельную папку:

```powershell
dotnet build -p:OutputPath=bin\Verified\
```

Для запуска в Revit необходим настроенный `.addin`-манифест, ссылающийся на DLL
и команду `RevitPlugin.HelloRevit`. Манифест в этом репозитории не предоставлен.

## Проверка расчётов

```powershell
pwsh -NoProfile -File tests\Regression.ps1
```

Проверки используют расчётные методы исходного кода с тестовой геометрией.
Размещение арматуры необходимо дополнительно проверить в модели Revit.

## Ограничения

- Поддерживаются прямые вертикальные стены.
- Для сборки требуется один однозначно определённый поддерживаемый класс бетона:
  C20/25, C25/30 или C30/37.
- Распознавание проёмов использует дискретное сканирование геометрии.

Исходники находятся в корне проекта, регрессионные проверки — в `tests/`.
Результаты сборки и локальные настройки исключены из Git.
